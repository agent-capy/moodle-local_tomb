# 0.3.0-alpha の実装記録

2026-09-20 JST。「start implement」に基づき、[計画](NEXT_PLAN.md)のC-01〜C-06を実装した。基準は0.2コミット `06aff50`、DB版は `2026092002`。作業枠の見積時間を実績として扱わず、48時間計画全体の完了とは区別する。

| 項目 | 結果 |
|---|---|
| C-01 履歴・受領管理 | 本人、作成代行、管理一覧を25件ずつ表示。コース・収集状態・受領状況で絞り込み、管理CSVは全ページを同じ選択条件で出力。125件の合成要求で境界を検証 |
| C-02 状態・再試行 | ZIPだけの再準備、新しい版の生成、容量待機・上限超過、材料欠損、Privacy削除、配送期限を区別。利用資格を失った版は履歴の説明だけを表示。申請間隔等の拒否はTomb画面内で説明し、コース選択を保持 |
| C-03 容量・分割処理 | 既知の共有原本、保存材料の仮予算、Privacy索引、一時ZIP、完成キャッシュを区別。収集・組立の時間、メモリ、容量を計測。Privacy監査の全件読み込みを250行単位の処理へ変更し、連鎖を検証 |
| C-04 日英表示 | Tombの画面・通知・静的ページの表示文を言語ファイルへ集約。作成時に日英を選択し、版の出力言語を固定。代行では本人の言語を使用。教材の翻訳は行わない |
| C-05 提出用デモ | 検証用コース10を保持し、自然な教材・提出物・講評のコース11を追加。通常画面・通常cronで学生版441、教師版442、英語の学生版443を作成し、主要7画面を撮影 |
| C-06 回帰・配布 | 自動157項目、ブラウザの権限・CSV・通知・取得・受取確認、静的33ページのJS有無、小画面、旧版のハッシュ、共有サイト稼働を確認。配布ZIP・文書・指定作者のコミットを作成 |

容量値は未収集の投稿・提出物などを含む上限ではない。5件は順次実行し、各ZIPは64 MiB未満、検証した材料は順次削除した。PHPピーク値はプロセス全体の値で、個別ジョブの独立した最大メモリではない。[実測値と試験条件](VALIDATION.md)を併せて参照する。

提出用デモは架空の学生2名と教師1名を使用する。既存問題バンクの基本問題を新しい小テストから参照し、元の問題・既存受験を変更しない。撮影のために一時付与したTomb管理権限は解除済み。

更新はTombだけを対象に行い、Moodle本体、他プラグイン、サービス設定を変更していない。比較用の0.1・0.2版を保持し、旧版Privacy移行ゲートも維持する。

次の残件は、本番規模の負荷・長時間配信、Windows/Safari実機、停止済み利用者への機関交付、自動リマインド、大量一括受付、詳細ルーブリック、新しい活動形式。GitHubは送信先と公開範囲が未指定のため、ローカルコミットまでとする。
