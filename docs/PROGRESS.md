# Tomb アルファ版の実装記録

2026-09-19 の WBS v1.0 完成後に着手し、2026-09-20 JST に 0.1.0-alpha を実装・検証した。ユーザーの「WBS 後に実装まで進める」「就寝中の判断は委任、破棄可能な PoC」という指示に基づく。工程別の実作業時間は計測していないため、WBS の見積時間を実績として扱わない。

本書の下表は初回PoCの到達点を起点に更新する。48時間計画全体の完了を宣言するものではない。

第1段階の本人向け出力を通した後、フォーラム・小テスト・教師版・作成代行・受領管理を追加した。初回検証後に配布物と実画面を整理し、今回の継続指示で0.2の機能と境界試験を追加した。検証環境は Moodle 5.0 のまま、Tomb は専用コーホート限定の検証モードで残す。

| A-01 検証準備 | 完了 | 専用コース10、学生2名・教師1名、添付・画像・公開/非公開評価・フォーラム・小テスト。既存問題を参照し、既存受験は変更しない |

この「完了」はアルファ版の実装・検証範囲を表す。本番閉鎖の準備完了や全Moodle版・全ブラウザ対応を意味しない。旧版材料を明示削除するPrivacy移行手順、停止済み利用者への機関交付、運用規模の負荷試験、完全な英語UIは残件。20名単位の受付・手動再通知は PoC の実装判断として明示する。

GitHub の送信先と公開範囲は未指定のため、ローカルコミットと配布物までを引き渡す。新規公開リポジトリは作成しない。
