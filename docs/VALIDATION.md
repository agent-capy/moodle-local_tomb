# 0.2.0-alpha 検証結果

2026-09-20 JST、プラグイン版 `2026092001`。Moodle 5.0 / PHP 8.4.20の同じ共有環境で、0.1からの追加実装を検証した。[初回PoCの検証](VALIDATION_0_1.md)を保存し、今回の結果と区別する。

## 追加・回帰試験

| 試験 | 結果 |
|---|---|
| 純粋処理 `tests/run.php --zip64` | 35 assertions PASS。ZIP構造・同一バイト列・65,536エントリ・HTML/パス等 |
| Moodle統合 `tests/integration.php --run` | 38 assertions PASS。教材・課題・成績・フォーラム・小テスト・削除・材料欠損・再構成を回帰確認。専用版26/27、最終回帰45/46（検証後に材料削除） |
| 教師権限 `tests/continuation.php --run` | 14 assertions PASS。未公開の課題評価・講評、非公開成績閲覧の有無、学生版への非混入、実名権限失効、本番移行ゲート。専用版12〜15は検証後に材料を削除 |
| Privacy `tests/privacy.php --run` | 25 assertions PASS。標準writerの実ZIP、他者版に残る本人の記録、教師個人の要求に全クラスを返さないこと、承認されたコンテキスト、使用中保護、本人と寄与分の消去、監査、材料削除後の参照、削除済みジョブ、手動採点者の講評 |
| モード競合 `tests/mode_race.php --run` | 1 assertion PASS。別プロセスの要求が待機中にTombを停止すると、ロック取得後に最新の運用設定を読み直して受付を拒否。元モードに復元 |
| 完成後の準備失敗 `tests/preparation_failure.php --run` | 2 assertions PASS。ZIP準備のロック競合でも完成した記録を保持。同じ計画で再準備し、成功時に古いエラーを解除。専用版33 |

既存の4 GiB超ZIP検証は[0.1の結果](VALIDATION_0_1.md)を参照。ZIP形式・連結コードは今回変更していないため、巨大ファイル試験を繰り返して実績を増やすことはしていない。

Privacy試験の初回は、DBから返るコンテキストIDの文字列/整数の比較で試験が停止した。数値として正規化して再実行した。合成要求の省略フィールドによる警告も修正し、最終25項目は警告なしで通過した。

## ブラウザ・固定版の検証

通常の画面から学生版36・教師版35を要求し、既存の通常cronで完成・通知・取得した。学生版34の作成代行も、成功・受付間隔による失敗を同じ受付結果表で確認した。最初のブラウザ試験はリンク末尾の矢印を省略した完全一致セレクタで失敗したため、実際のリンクに合わせて再検証した。

- 学生版：6,278,239 bytes、133エントリ、HTML 15ページ。SHA-256 `cd4911d8db05401caefd6a15c1648aa1c0b0faff0fecdfeb4e981187de395cb3`。
- 教師版：6,280,476 bytes、135エントリ、HTML 16ページ。SHA-256 `93934162db5919f74fccc7049cb4d9de7f16261e1a4fef3ec33484891e117532`。
- 両ZIPのCRC、再取得の全バイト一致、HTTP Rangeの100〜199バイト・206応答・`no-store`を確認。相互に他者の取得URLへアクセスすると拒否された。
- 全31ページをJavaScript有効／無効の両方でオフライン表示。外部通信・ブラウザエラー・欠損画像・横はみ出し0。両版それぞれ3ページを390px幅でも確認し、課題の印刷PDFを保存。
- 教師版の非公開評価用マーカーを確認し、学生版に含まれないことを検査。
- 旧版2・11は元データを再収集せず、固定材料からキャッシュを再構成。以前のSHA-256 `8f1c8436e488e4aebbdb734f2f809526382c7c77d96e0af196e8db5e129b58fc` / `21628304f5152eb0206c9647406361c24f548c837085c833fec44a317f9b680a` と一致。

スクリーンショット11枚を[一覧](SCREENSHOTS.md)に追加した。手動講評の索引追加はこれらのZIP取得後に行ったため、追加後に統合38項目とPrivacy25項目を再実行した。既存の受験を保存変更せず、メモリ上で加えた採点ステップにより投稿者の対応を試験した。

## 最終環境確認

09:07 JST時点でMoodle 5.0 / PHP 8.4.20、Tomb `2026092001`、検証モード。メンテナンス無効・保留アップグレードなし・他プラグインを含む版不一致なし。通常cronの最終実行23秒前、監査連鎖正常、容量正常。テストで付けた管理・実名出力権限は残っておらず、Privacy専用nologinアカウントは全て削除済み。課題の公開設定も復元し、既存コース5件を保持した。通常コースとログインページはブラウザでも正常表示。
