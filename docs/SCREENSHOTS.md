# 画面例

0.3.0-alphaの実画面。架空の学生・教師と専用デモコースを使用している。教材・提出物・講評はデモ用に作成し、小テストでは検証環境にある問題バンクを再利用した。

画面操作とバックグラウンド処理の関係は [操作と処理のシーケンス図](SEQUENCE.md)を参照してください。

## 利用者：残すコースを選び、学習記録を受け取る

| 画像 | 操作・説明 |
|---|---|
| [出力要求](screenshots/0.3/08-learner-request.png) | 保存したいコースと出力言語を選び、「記録を作成して受け取る」から収集・ZIP準備を依頼する。過去の記録も同じ画面で確認できる |
| [完成通知と取得](screenshots/0.3/05-download-and-notification.png) | Moodle標準の通知から完成した記録を開き、本人がZIPをダウンロードする。展開・内容確認後は受取確認を送信する |
| [学習記録のホーム](screenshots/0.3/01-offline-home-ja.png) | ZIPをすべて展開し、`index.html`からコースの教材と学習成果へ入る。閲覧にMoodleへのログインは不要 |

本人が要求すると、バックグラウンドで収集とZIP準備が進む。ページを開いたまま待つ必要はない。ダウンロード後は添付も含めて記録を確認し、Moodleへ戻って受取確認を送信する。

## 管理者：受付方法を整え、受領状況を確認する

| 画像 | 操作・説明 |
|---|---|
| [運用モードと設定への入口](screenshots/0.3/09-administrator-controls.png) | 運用モードを選び、容量・配送期限・検証対象の設定へ進む。画像は検証モードの状態 |
| [コース単位の一括受付](screenshots/0.3/10-administrator-batch-request.png) | 対象コースを選択し、右側で学生を選んで「選んだ学生の記録を準備」を実行する。1回20名まで。左側には教師版の作成フォームがある |
| [未受領の管理](screenshots/0.3/07-receipt-management.png) | コース・収集状態・受領状況で絞り込み、同じ条件のCSVを取得する。未受領の利用者へ再通知できる |

一括受付は本人の要求を補う経路。代行で収集が完了すると本人へ通知され、学生本人がログインしてZIP準備と取得を行う。通知済み、取得開始、本人による受取確認を区別して管理する。教師も、権限のある担当コースで学生版の作成を代行できる。

出力要求と一括受付の画像は、対象を選択した送信前の状態を示している。

## 保存した内容を読み返す

| 画像 | 説明 |
|---|---|
| [提出とフィードバック](screenshots/0.3/02-assignment-ja.png) | 考察本文・添付・評価・教師の講評を一緒に読み返す |
| [保存した小テスト](screenshots/0.3/03-quiz-ja.png) | 保存済み回答、正誤、ローカル表示の数式、公開フィードバック |
| [教師の保存記録](screenshots/0.3/06-teacher-assignment-ja.png) | 採点権限で閲覧できる参加者別の提出・評価を保存。投稿者欄は仮名が標準 |
| [英語のホーム](screenshots/0.3/04-offline-home-en.png) | Tombの表示は英語、元の日本語コース名・教材本文は保持 |

画像はブラウザの表示範囲または要素を直接撮影したもの。環境固有のURLを含むフッターは撮影範囲から除いている。
