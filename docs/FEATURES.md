# 機能と対応範囲

0.3.0-alphaの実装状況。検証環境はMoodle 5.0 / PHP 8.4。対応範囲と試験結果はアルファ版のものであり、本番運用や未検証環境での動作を保証するものではない。

| 機能 | 対応範囲 |
|---|---|
| 基盤 | 設定・権限・4つの運用モード・診断・容量見積CLI。日本語・英語の画面と固定出力言語 |
| 生成要求 | コース選択、本人・代行の要求、進捗、重複抑止、通常cron、停滞・失敗時の案内 |
| 教材 | ファイル・フォルダ・ページ・ラベル。ObjectFS対応、相対リンク、収集中に削除された資料の整合除外 |
| 課題・成績 | 本人の提出本文・添付・公開講評・添付・公開成績 |
| フォーラム | 可視投稿・返信・添付、投稿者の仮名化。公開期間・グループ・Q&Aの可視性に対応 |
| 小テスト | 保存済み受験を本人のレビュー権限で出力。多肢選択・○×・記述・数値・組み合わせの5形式を検証。未完了・未対応は注記 |
| 静的ページ | ホーム・活動・成績・注記・manifest・README・版比較。画像、ローカル数式、印刷、JavaScript無効時の本文閲覧 |
| ZIP | 固定したSTORE/DEFLATEとZip64。同じ版の再構成が同じバイト列になる。65,536エントリと4 GiB超ファイルを検証 |
| 配信・通知 | 本人認証・所有者確認・Range・非同期完成通知。容量予約、使用中保護、キャッシュ清掃、配送期限、材料削除 |
| 整合性・監査 | 期待ページ数、CRC・ハッシュ・内部リンク検査。材料欠損時の版停止、監査連鎖とJSONL出力 |
| 教師版 | 仮名が標準。実名は別権限と理由を要する。採点・成績閲覧権限に応じた未公開評価・講評に対応し、権限失効後は取得を拒否 |
| 作成代行 | 教師が学生版を用意し、学生本人がZIP準備・取得。教師による学生版の取得は拒否 |
| 一括受付 | 管理者がコースを選び、1回20名まで受付。利用者別に成功・失敗を表示 |
| 履歴・受領管理 | 25件単位のページ送り、コース・状態・受領状況の絞り込み、同条件のCSV。通知・取得開始・本人確認を区別。手動再通知 |
| 個人データ | Privacy APIの検索・出力・承認済み削除。他者版への寄与内容も追跡。索引のない旧版には移行ゲート |
| 容量 | 既知の添付量と未確定部分を区別した仮予算。収集・組立の時間、プロセスピークメモリ、保存量の実測 |

## 動作確認の範囲

Moodle 5.0 / PHP 8.4で、権限、固定ZIP、Privacy API、履歴・CSV、日英表示を確認している。静的HTMLはChromiumでJavaScript有効・無効の表示と390px幅を確認した。容量計測は少数の順次実行であり、本番規模の性能試験ではない。

実際の画面は [スクリーンショット](SCREENSHOTS.md)、導入と運用、試験コマンドは [運用手順](OPERATIONS.md)を参照。

## 未対応・未検証

Windows/Safari実機、他のMoodle版、本番規模の負荷・長時間配信は未検証。自動リマインド、サイト横断の大量一括受付、停止済み利用者への機関交付、詳細ルーブリック、新しい活動形式、日英以外の画面翻訳は今後の対象。

旧版の個人データ索引を推測で後付けする機能はなく、[Privacy移行手順](PRIVACY.md)による明示的な対応が必要。
